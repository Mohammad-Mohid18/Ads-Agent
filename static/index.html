System Architecture & Docs

1. Executive Overview & Architecture

The AI Video Ad Engine automatically converts any public business website URL into three distinct, production-ready video ads. It orchestrates asset harvesting, script generation, voiceover synthesis, AI visual generation, dynamic fallback management, and multi-template video composition.

2. Pipeline Workflow Breakdown

  • 1. Scraping & Asset Extraction: Parses target HTML to JSON, capturing brand colors, value props, and images.
  • 2. LLM Scripting: Processes metadata through LLM APIs into scene breakdowns and visual prompts.
  • 3. Voiceover Processing: Synthesizes audio and stitches multi-scene tracks using container-level FFmpeg.
  • 4. Multi-Tier Visual AI: Primary: Pollinations AI (FLUX) ➔ Secondary: Fal.ai/HuggingFace ➔ Tertiary: Pexels API.
  • 5. Video Assembly: Merges cached public assets, text overlays, and audio in Creatomate API to output MP4s.
  • 6. In-Dashboard Editor: Allows live inspection of scripts, audio tracks, and visual assets with instant re-render capabilities.

3. Infrastructure & Core Stack

  • Backend: Python 3.13 / FastAPI
  • Media Processing: FFmpeg (Nixpacks buildpack)
  • Database & Storage: Supabase / PostgreSQL
  • Deployment & CI/CD: Railway Cloud
  • Frontend: HTML5 / CSS3 / JS (Code Club Dark Mode)

4. API Usage: Free Tiers vs. Paid Tier Upgrades

A. Video Rendering Engine (Creatomate)

  • Current Free Tier: 50 free video renders per month.
  • Paid Upgrade Options: Starter Plan (~$41–$49/mo) for ~2,000 renders without watermarks; Growth Plan (~$99–$129/mo) for high-volume priority queues and Creatomate JS SDK access.
  • JS SDK Advantages: Enables in-browser WebGL canvas video previews, allowing users to make live text or image edits locally without incurring backend API costs or render latency.

B. Visual Generation Tiers (Pollinations / Fal.ai / Hugging Face)

  • Current Free Tier: Unlimited public generation via Pollinations AI (with server 500 fallback handling); free tier credits on Fal.ai/Hugging Face.
  • Paid Upgrade Options: Dedicated FLUX worker instances on Fal.ai/Replicate ($0.001 - $0.003 / image).
  • Advantages: Eliminates stock photo fallback triggers and guarantees sub-3-second image generation.

C. Voice Synthesis (ElevenLabs)

  • Current Free Tier: 10,000 characters/month (~20 video ad scripts).
  • Paid Upgrade Options: Starter Plan ($5/mo) for 30,000 chars; Creator Plan ($22/mo) for 100,000 chars.
  • Advantages: Unlocks custom brand voice cloning and full commercial rights.

D. Database & CDN (Supabase)

  • Current Free Tier: 500 MB DB + 1 GB Storage + 2 GB Bandwidth.
  • Paid Upgrade Options: Pro Plan ($25/mo) for 8 GB DB + 100 GB Storage + auto-backups.
  • Advantages: Prevents schema cache locks and provides permanent CDN storage for historical ad assets.

E. Cloud Hosting (Railway)

  • Current Free Tier: $5 trial execution credit.
  • Paid Upgrade Options: Hobby/Pro Plan ($5/mo base + usage).
  • Advantages: Dedicated CPU/RAM allocations, eliminating worker timeouts during heavy FFmpeg audio stitching.
